    泽田大樱桃苗木专业合作社位于烟台福山、中国樱桃重镇张格庄镇和门楼镇，下设三个基地，一个育苗基地，两个成品苗基地。

    合作社拥有多年多品种栽培与销售经验，坚持以客户和市场为导向，持续创新发展。2024年以来有美早、佳红、俄八、水晶、弗里斯科、辉煌等优质品种，

    泽田苗木同烟台农科院，青岛农业大学，烟台大樱桃协会的多名专家学者一起，进行技术上的攻关，从栽培方法到病虫害防治方法进行一系列的研发和改进，同时泽田苗木用这些宝贵经验为种植户提供长期技术支持，并且对于规模购买规模种植的种植户可以莅临当地进行指导。

    我们保证品种纯正，不出售早期落叶苗，根瘤菌苗等次等苗，欢迎各位客户现场考察，交流，现场起苗，装车发货。

    问题解答

    大樱桃苗什么时间种采购和播种比较合适？

    栽植适期为每年11月至翌年3月

    泽田苗木都有哪些品种？

    2024: 美早、佳红、俄八、水晶、弗里斯科、辉煌等优质品种

    2021: 佳红、美早、龙冠、俄八、布鲁克斯、美国1号、福金、大粒水晶等三十余个品种

    2020: 福星、龙冠、美早、大粒水晶、红灯、俄八、黄密、外引7号、斯坦勒、黑珍蛛、沙密特、布鲁克斯、红1、福翠、冰糖樱、冰翠、黄星等品种

    2017: 宽叶美早、龙冠、福星、福辰、俄罗斯八号、美国一号、岱红、万润七号、新红、冰糖樱等多个品种

    泽田的樱桃树苗耐受性如何？

    是的。我们的樱桃苗经过精心筛选与培育，对常见樱桃树病害具有较强抗性，能够确保其健康、稳定地生长。

    购买后是否提供樱桃苗养护指导？

    是的。我们提供详细的养护指导，并在后续生长过程中持续提供技术支持，确保您的樱桃树健康生长并实现高产优质。

    泽田苗木是否可以协助大型种植项目？

    可以。我们在支持大规模樱桃果园项目方面拥有丰富经验，可提供优质苗木供应、种植技术指导以及持续的后期支持，助力项目顺利实施并取得成功。
